# eポートフォリオ（カルテ）システム 操作マニュアル

## このシステムについて

学生一人ひとりの学びの記録をためておく「カルテ（個人ノート）」です。

| | Slack | eポートフォリオ |
|---|---|---|
| 種類 | フロー型 | ストック型 |
| 得意なこと | その場のやり取り・連絡 | 記録を積み重ねて、あとから振り返る |
| 情報 | 時間がたつと流れていく | 個人ごとに整理されて残る |

- **学生**は、出席、授業チャンネルへの書き込み、未来創造PJ、活動の様子などの記録と、作品をカルテに残します。
- **教員**は、学生のカルテを閲覧し、メッセージやコメントで学生と対話します。

ブラウザで `http://127.0.0.1:8080`（公開している場合はそのURL）を開いて使います。

---

## 1. はじめに（共通）

### 1-1. 学生登録（学生のみ・初回だけ）
1. ログイン画面の右上にある「**学生登録**」を開きます。
2. 次の項目を入力して「**登録**」を押します。
   - **学籍番号**：これがそのまま**ログインID**になります（例：`s2522001`）
   - **氏名**
   - **パスワード**：8文字以上で、英字と数字を両方含めてください
   - **パスワード（確認）**：同じパスワードをもう一度入力します
   - **登録コード**：教員から配られた場合だけ入力欄が表示されます
3. ログイン画面に戻るので、学籍番号とパスワードでログインします。

> 教員アカウントは画面からは作れません。管理者がコマンド（`flask --app app create-user`）で作成します。

### 1-2. ログイン・ログアウト
- **ログイン**：「学籍番号（教員はログインID）」と「パスワード」を入力して「ログイン」を押します。
- **ログアウト**：画面右上の自分の名前 →「**ログアウト**」。共用のパソコンでは、使い終わったら必ずログアウトしてください。

### 1-3. 安全のための仕組み（知っておくこと）
- **30分間なにも操作しないと、自動でログアウト**されます。もう一度ログインしてください。
- パスワードを**5回続けて間違えると、10分間ログインできなく**なります。時間をおいてから試してください。
- 「フォームの有効期限が切れたか、不正な送信です」と表示されたら、ページを開き直してからもう一度操作してください。

### 1-4. ログインID・パスワードの変更
画面右上の自分の名前から変更できます。

- **学籍番号（ログインID）の変更**：新しいIDと、本人確認のための現在のパスワードを入力して「変更する」を押します。次回からは新しいIDでログインします。
- **パスワード変更**：現在のパスワード、新しいパスワード（2回）を入力して「変更する」を押します。

### 1-5. パスワードを忘れたとき（学生）
メールは使わず、教員から受け取る「**再設定コード**」で新しいパスワードを設定します。

1. ログイン画面の「**パスワードを忘れた場合**」を開きます。
2. 学籍番号を入力して「**教員にリセットを依頼する**」を押します。
3. 教員から再設定コード（例：`ABCD-2345`）を受け取ります。
4. 「**再設定コードを持っている場合**」を開き、学籍番号・再設定コード・新しいパスワード（2回）を入力して「**パスワードを再設定する**」を押します。
5. 新しいパスワードでログインします。

- 再設定コードは**24時間以内に1回だけ**使えます。5回間違えると使えなくなるので、そのときは教員にもう一度発行してもらってください。
- 教員がパスワードを忘れた場合は、管理者がコマンド（`flask --app app reset-password`）で再設定します。

## 2. 学生の使い方

ログインすると「**マイカルテ**」が開きます。画面上部のメニューは次のとおりです。

| メニュー | できること |
|---|---|
| マイカルテ | 自分の記録の一覧・集計を見る |
| 記録する | 新しい記録を書く |
| 作品 | 作品の一覧を見る・登録する |
| 対話 | 教員とのメッセージを見る・送る（未読があると赤い数字が出ます） |

### 2-1. カルテ画面の見方
- 上部：氏名、学籍番号、学年、**未来創造PJの配属**、自己紹介
- タブ：「**記録**」「**作品**」「**対話**」を切り替えます。
- 件数カード：記録の種類ごとの件数です。カードを押すと、その種類の記録だけが表示されます。
- 出欠の集計：出席・遅刻・欠席・公欠の回数です。
- 絞り込み：「種類」と「キーワード」（タイトル・内容・授業名）で探せます。

### 2-2. プロフィールを設定する
カルテ画面の「**プロフィール編集**」から、氏名・学年・**未来創造PJの配属**・自己紹介を入力して「保存」を押します。
未来創造PJの配属が決まったら、ここに入力してください（教員が学生一覧でPJごとに絞り込むときに使います）。

### 2-3. 記録する
メニューの「**記録する**」（またはカルテ画面の「＋ 記録する」）を開いて入力し、「保存」を押します。

| 項目 | 入力する内容 |
|---|---|
| 種類 | 出席／授業チャンネルへの書き込み／未来創造PJ／活動の様子／その他 |
| 日付 | 記録する日（最初は今日の日付が入っています） |
| 授業名・チャンネル名・PJ名 | 例：`Webアプリケーション開発`、`#web-app-dev`、`地域活性化PJ` |
| 出欠 | 種類が「出席」のときだけ表示されます（出席・遅刻・欠席・公欠） |
| タイトル | 必須 |
| 内容 | 学んだこと、書き込んだ内容、活動の様子など |
| 関連リンク | Slackのメッセージのリンクなど（`http://` か `https://` で始まるもの） |

**種類ごとの記録の例**
- **出席**：授業ごとに出欠を残す。タイトルは「第9回 ORマッピング」など。
- **授業チャンネルへの書き込み**：Slackで質問・発言した内容を要約し、そのメッセージのリンクを「関連リンク」に貼る。
  Slackのメッセージにマウスを乗せて「…」→「**リンクをコピー**」でリンクを取得できます。流れていくSlackの発言を、カルテにストックとして残せます。
- **未来創造PJ**：ミーティングや作業の内容、決まったこと、次にやること。
- **活動の様子**：ハッカソン、学外活動、資格の勉強など。

**記録の編集・削除**：記録の一覧からタイトルを押して詳細を開き、「**編集**」または「**削除**」を押します。削除した記録は元に戻せません。

### 2-4. 作品を登録する
「作品」タブの「**＋ 作品を登録**」を開いて入力し、「保存」を押します。

| 項目 | 入力する内容 |
|---|---|
| 作品名 | 必須 |
| 説明 | 作品の概要、工夫した点、担当した部分など |
| 外部リンク | GitHub、YouTube、公開しているWebサイトなどのURL |
| ファイル | 画像（png / jpg / jpeg / gif / webp）またはPDF。10MBまで |

- **ファイルと外部リンクの少なくとも一方**を登録してください（両方でも構いません）。
- 画像の作品は一覧にサムネイルが表示されます。
- 拡張子だけを変えたファイル（例：中身が画像ではない `.png`）は、安全のため登録できません。
- 編集でファイルを選び直すと、前のファイルと置き換わります。
- 作品のファイルは、本人と教員しか見られません。

### 2-5. 教員と対話する
- **カルテ全体へのメッセージ**：メニューの「**対話**」（または「対話」タブ）で、メッセージを入力して「送信」を押します。
- **記録・作品へのコメント**：記録や作品の詳細画面の下にある「コメント」欄から送ります。
- 教員から新しいメッセージが届くと、メニューの「対話」に赤い数字が出ます。開くと既読になります。
- 自分のメッセージを教員が読むと「**既読**」と表示されます。
- 対話の画面には、記録・作品へのコメントもまとめて表示されます。Slackと違って流れていかないので、あとから振り返れます。

> 他の学生のカルテ・作品・メッセージは見えません。自分の記録を見られるのは、自分と教員だけです。

## 3. 教員の使い方

ログインすると「**学生一覧**」が開きます。教員はカルテを**閲覧**し、**対話**します。学生の記録や作品を編集・削除することはできません。

### 3-1. 学生一覧
| 列 | 内容 |
|---|---|
| 学籍番号・氏名 | 氏名を押すと、その学生のカルテが開きます |
| 未来創造PJ | 学生が登録した配属先 |
| 記録・最終記録日 | 記録の件数と、いちばん新しい記録の日付（しばらく記録がない学生を見つけるのに使えます） |
| 作品 | 作品の件数 |
| お知らせ | **未読○件**（学生からの未読メッセージ。押すと対話画面が開きます）、**PWリセット依頼**（パスワードのリセットを依頼している学生） |

- 上の検索欄で、**氏名・ID・学籍番号**で探したり、**未来創造PJ**で絞り込んだりできます。
- メニューの「学生一覧」の横の赤い数字は、全学生からの未読メッセージの合計です。

### 3-2. 学生のカルテを見る
学生一覧で氏名を押すと、その学生のカルテが開きます。

- 「**記録**」タブ：種類ごとの件数、出欠の集計、記録の一覧。種類やキーワードで絞り込めます。タイトルを押すと詳細を見られます。
- 「**作品**」タブ：作品の一覧。詳細画面では、ファイルの表示・ダウンロードと、外部リンクを確認できます。
- 「**対話**」タブ：その学生とのメッセージのやり取り。

### 3-3. 学生と対話する
- **カルテ全体へのメッセージ**：「対話」タブで入力して「送信」を押します。
- **記録・作品へのコメント**：記録や作品の詳細画面の「コメント」欄から送ります。具体的な記録に対するフィードバックに便利です。
- 学生からのメッセージは、開くと既読になります。教員が送ったメッセージを学生が読むと「既読」と表示されます。
- 未読の管理は教員全体で共有しています（どの教員が開いても既読になります）。

### 3-4. パスワードの再設定コードを発行する
学生がパスワードを忘れたときに使います。

1. 学生一覧の「お知らせ」に「**PWリセット依頼**」と出ている学生のカルテを開きます（依頼がなくても発行できます）。
2. カルテ上部の「**パスワード再設定コードを発行**」を押し、確認画面で OK を押します。
3. 表示された再設定コード（例：`ABCD-2345`）を、**対面などの確実な方法で本人に**伝えます。
   - コードは**この画面でしか表示されません**。メモを取るか、その場で伝えてください。
   - 有効期限は24時間で、1回だけ使えます。もう一度発行すると、前のコードは使えなくなります。
4. 学生はログイン画面の「パスワードを忘れた場合」→「再設定コードを持っている場合」から、新しいパスワードを設定します。

## 4. よくある質問

| 困ったこと | 対処 |
|---|---|
| ログインできない | 学籍番号（ログインID）とパスワードを確認してください。5回続けて失敗すると10分間ログインできません |
| パスワードを忘れた | 学生は「1-5. パスワードを忘れたとき」の手順で再設定します。教員は管理者に依頼してください |
| 急にログイン画面に戻った | 30分間操作がなかったため、自動でログアウトしました。もう一度ログインしてください |
| 「不正な送信です」と出た | ページを開き直してから、もう一度操作してください |
| 「ファイルが大きすぎます」と出た | 10MB以下にしてください。動画などの大きな作品は、YouTubeなどに置いて外部リンクで登録してください |
| ファイルが登録できない | 画像（png / jpg / jpeg / gif / webp）とPDFだけ登録できます |
| 出欠の欄が出ない | 種類を「出席」にすると表示されます |
| 他の学生のカルテが見たい | 学生は自分のカルテしか見られません（プライバシー保護のため） |
